TASC

Turbo Agent Skills CLI helps you manage, evaluate, watch, and improve your reusable coding-assistant skills.

What TASC does

  • Install and track agent skills across the local coding-assistant environment
  • Watch trusted skill sources for updates
  • Evaluate skills with repeatable scenarios
  • Run cross-skill consistency checks
  • Turn findings into actionable insights

Built on the right foundations

TASC intentionally reuses GitHub CLI for lifecycle operations and the GitHub Copilot SDK for the agent surface. Evaluation is grounded in Waza patterns, while consistency checks borrow Kratos-style conflict analysis without a hard dependency.

Local-first trust

Skills, evaluation traces, and consistency findings stay local by default unless the user explicitly requests a broader export or sharing flow.
